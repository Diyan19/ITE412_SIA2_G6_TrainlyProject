## Project Title

**Trainly: A Gym Management and Booking System for Gyms with Member Monitoring**

## Project Description

Trainly is a web-based gym management and booking system designed for small and medium-sized gyms. The system helps gym owners and staff manage members, monitor memberships and attendance, and organize gym bookings and schedules. Gym members can use the system to reserve workout schedules, check gym information, and locate nearby gyms.
